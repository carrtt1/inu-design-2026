# inu-design-2026

2026 인천대학교 디자인학부 졸업전시회 「꾹 : PRESS OUR MARK」 본 전시 홈페이지 (Vite + React)

## 실행
```bash
npm install
npm run dev
```

## 이미지 넣기
`src/assets/` 에 파일을 넣고 `src/App.jsx` 상단 `IMAGES`, `src/content.js` 의 `MENU_ITEMS[].icon` 에 연결.

## 배포
GitHub 저장소 `inu-design-2026` 로 push → Vercel 에서 Import (프로젝트 이름 `inu-design-2026`) → https://inu-design-2026.vercel.app
